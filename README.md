# にゃ Neko Room — Kawaii Gamer Room

貓咪少女房間模擬  
拖家具、換配色、調日光——Three.js + Vite

## 跑起來

```bash
npm install
npm run dev
```

開 [http://localhost:5175](http://localhost:5175)

```bash
npm run build
```

## 操作

- 拖家具移動，`R` 或雙擊旋轉
- 色票拖到牆／地板／織品換色
- 左鍵轉視角、右鍵平移、滾輪縮放
- 可截圖、錄影、複製分享連結
